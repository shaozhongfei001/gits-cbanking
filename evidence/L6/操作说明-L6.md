## 4. 故障处理

| 现象 | 期望行为 | 禁止 |
|---|---|---|
| 图服务不可用 | HTTP **503**，降级到既有 RAG 路径 | 返回 200 空结果 |
| 依赖服务不可用 | 503 明确报错 | 静默成功 |
| 快照不可用 | `SNAPSHOT_UNAVAILABLE` | 用最新数据伪装历史复算 |
| 动作超时 | `RESULT_UNKNOWN`，**先查目标回执** | 直接判失败 |
| 并发版本冲突 | 409 / CAS 拒绝 | 覆盖写 |
| 幂等键不同 payload | 409 `IDEMPOTENCY_CONFLICT` | 重复执行 |

## 5. 保留与恢复

- **RPO**：最近成功持久化快照（`LATEST_SUCCESSFUL_PERSISTED_SNAPSHOT`）
- **RTO**：**已实测**，具体目标值待运维提交（C08 §6 要求实测后提交）
- 删除必须留 **tombstone**，不得可重放
