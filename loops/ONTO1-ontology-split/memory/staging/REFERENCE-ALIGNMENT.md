## 3. 矩阵判据（栏位定义与判定规则）

| 栏位 | 取值域 | 判定规则 |
|---|---|---|
| 条款号 | 正式文本目录编号（形如 5.2.1） | 必须逐字取自正式文本；不得凭印象或二手资料填写；文本未到手留空 |
| 适用性 | 适用 / 不适用 | 二值闭集；「不适用」必须在下一栏给出理由 |
| 不适用理由 | 必填（当且仅当适用性=不适用） | 须指向本项目范围与建模事实，不得写成技术偏好或工作量理由 |
| 项目加严 | 是 / 否 | 「是」表示本项目要求严于该条款（内部工程控制），必须在「证据」栏给出可执行证据 |
| 证据 | 文件:行 / 门禁命令 / 制品哈希 | 禁止填「已评估」「已确认」等无载体表述 |
| 结论 | 参照对齐 / 不适用 / 项目加严 | 三值闭集；不得出现「符合」类结论 |

**判定纪律（fail-closed）**

1. 任一行缺证据或缺「不适用理由」⇒ 该行无效，矩阵不得提交 T3；
2. 文本未到手 ⇒ 数据行必须为 0（由 `--gate` 强制，含骨架与机读 CSV 两处）；
3. **「适用性=适用」不等于符合性结论**：本矩阵只表达参照关系，不产生任何符合性声明；
4. 逐条判定人须与复核人分离；结论栏不得由同一人既填又签；
5. 判据变更（栏位、取值域、判定规则）须记入本文件变更记录并经公共语义 Owner 确认。

机读载体：`loops/ONTO1-ontology-split/evidence/wi-a3-clause-matrix-EMPTY.csv`（表头：条款号,适用性,不适用理由,项目加严,证据,结论）。
