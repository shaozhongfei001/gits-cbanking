- **Gate**：`l6_runtime_acceptance_tests`

- **退出码**：0（**期望非 0**）

- **根因**：与 FAIL-2026-09-12-02 / -07 / -11 / -12 / -14 同一模式 ——
  验收报告是**合规正例**（无静默降级、删除后不可重放、RTO 已实测、trace 完整），
  故这些断言在正例上**恒真**。`violations` 段虽是**可执行**的，
  但只覆盖了 `detect_violations()` 已登记的分支；
  **「静默降级」与「删除后可重放」两项的判定写在主流程里，
  违规夹具走的是另一条简化分支**，两者未共用同一真值函数，
  导致主流程断言仍可被禁用而不被发现。
- **合规影响**：L6 退出标准是「无未关闭 BLOCKER/MAJOR」，
  而这些是**否定式**安全断言（不得静默降级、不得删除后可重放）。
  空转意味着最外层验收未能证明基本安全属性。
- **下一动作**：统一为**单一真值函数**（与 L3-2 / L4-2 同构），
  正例与违规夹具共用同一判定；主流程改为调用该函数。
