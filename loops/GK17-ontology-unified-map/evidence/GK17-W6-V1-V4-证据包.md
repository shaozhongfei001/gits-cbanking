绊线的用途：将来本体内容真的参与选择时它**会失败**，从而**强制更新本声明**（防声明腐化）。

### ⚠ V3 锚定空间限制（必须随证据读）

门禁的锚点是**既有权威 ID 空间**：`KM-*`(地图) / `KD-*`(域) / `ASSET-*` / `SP-*` / `AC-*` / `RP-*`，
以及 `entrypoints.tasks` **对齐本体 `gits:TaskType`**。
⇒ 它是**"地图 → 既有权威 ID 空间（含任务类型对齐本体）"**的锚定，
**不是**"地图 → **A-Box 个体**"的锚定（本体 `individuals=0`）。
本 Loop 自己把这个洞写在脚本 docstring 的「既有缺口/诚实缺口」里。
**该限制是 WP3.2/W4 完成前的能力边界；须由 ACCEPT 裁定 V3 是否视为通过。**
