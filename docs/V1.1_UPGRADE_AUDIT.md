## 十、风险与建议

1. **最高风险**: Human Gate前端完全缺失 — 27个P0场景中大部分涉及HG，这是V1.1的核心安全机制
2. **次高风险**: 无录音降级模式 — V1.1明确要求客户拒绝录音场景，影响证据采集全链路
3. **数据层风险**: ScenarioSeedDataService需重构支持SCENARIO_DATA_ROOT，否则无法加载V1.1数据
4. **前端架构风险**: 无Pinia状态管理，跨组件HG决策传递困难
5. **API占位风险**: fetchReport/fetchCustomerJourneys/fetchJourneyClaims/fetchOperatingCases为空实现

**建议执行顺序**: 数据层重构 → HG通用组件 → 后端HG补全 → 逐P0场景补齐 → 联调 → 回归
