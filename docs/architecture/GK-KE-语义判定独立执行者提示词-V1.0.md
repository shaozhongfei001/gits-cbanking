```

INCONCLUSIVE   —— 观测不足以判定（如所需输入差异未产生、输出无法观测）
NOT_APPLICABLE —— 该判据在当前场景不适用（须说明理由）
```

## ⚠️ 四条硬性约束

1. **`INCONCLUSIVE` 不得记为 `PASS`**（判据文档 §3 明文）
2. **必须逐条列出判定**，不得只报汇总或通过率（G-6）
3. **不得修改判据文档**；若你认为判据本身有缺陷，**如实记录于报告**，但**不修改**
4. **不得修改观测文件**（你只判定，不改证据）
