### §三.4 S1–S5 判据**本身设计是否合理**

这是本轮最需要你独立判断的地方。

**请判断**：
1. S1–S5 **是否真的可观测**？接入真实 LLM 后能否执行？
   （若某条**技术上无法观测**，则届时存在"删除该条以让整体通过"的诱因 ——
     这正是预注册要防的事，而判据设计本身可能埋了这个雷）
2. **S3（未执行 ≠ 无冲突）** 是否真的能通过输出区分？
