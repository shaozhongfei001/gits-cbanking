## D.5 迭代环与建议书 Tab 的联动

### D.5.1 迭代环 → 建议书

| 迭代环事件 | 建议书 Tab 响应 |
|-----------|----------------|
| POSTVISIT 完成 | 自动触发 SP-21，候选记忆出现在交互记忆面板 |
| 新证据录入 | 建议书版本列表显示"有新证据可更新"提示 |
| 迭代轮次增加 | 闸门进度自动检查是否满足推进条件 |

### D.5.2 建议书 → 迭代环

| 建议书事件 | 迭代环 Tab 响应 |
|-----------|----------------|
| 建议书更新 | PREVISIT 访前准备自动引用最新建议书 |
| 闸门推进 | 迭代环阶段指示器更新 |
| 对客版发布 | INTERACTION 会面脚本自动调整话术 |

### API 层

```typescript
// frontend/src/api/proposal.ts
export const proposalApi = {
  generateDraft: (command: ProposalCommand) =>
    httpPost<ProposalDraft>('/api/v1/engagement/proposal/generate', command),

  listVersions: (customerId: string) =>
    httpGet<ProposalVersion[]>(`/api/v1/engagement/proposal/${customerId}/versions`),

  getVersion: (customerId: string, versionId: string) =>
    httpGet<ProposalVersion>(`/api/v1/engagement/proposal/${customerId}/versions/${versionId}`),

  advanceGate: (command: GateAdvancementCommand) =>
    httpPost<ProposalVersion>('/api/v1/engagement/proposal/gate/advance', command),

  generateCustomerVersion: (customerId: string, versionId: string) =>
    httpPost<ProposalVersion>(`/api/v1/engagement/proposal/${customerId}/versions/${versionId}/customer-version`),
}

// frontend/src/api/interaction-memory.ts
export const interactionMemoryApi = {
  extractCandidates: (interactionId: string) =>
    httpPost<CandidateMemory[]>(`/api/v1/engagement/interaction-memory/extract`, { interactionId }),

  confirmCandidate: (memoryId: string, confirmed: boolean, revisedContent?: string) =>
    httpPost<void>(`/api/v1/engagement/interaction-memory/${memoryId}/confirm`, { confirmed, revisedContent }),

  getEffectiveMemories: (customerId: string) =>
    httpGet<InteractionMemory[]>(`/api/v1/engagement/interaction-memory/${customerId}/effective`),

  getMemoriesByCategory: (customerId: string, category: MemoryCategory) =>
    httpGet<InteractionMemory[]>(`/api/v1/engagement/interaction-memory/${customerId}/category/${category}`),
}
```
