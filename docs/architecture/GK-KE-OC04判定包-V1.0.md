**我方判定**：**代码完全可达** → **不是死代码** → **真实问题是文档与代码不一致**。

我方若自行判定"可用"，即违反 AGENTS.md「不得凭名称/近似认定兼容」；
若自行判定"应删"，则会**破坏仍在工作的代码**。

**已采取动作**：已发函（P0 优先级）请求裁定。

**解除条件**：KERT 维护方裁定后，我方重跑探针；若转 `PASSED`，编译解除阻断。
