---

## 1. 裁定原则（**先立规矩，再列清单**）

依建议书 §14.2 原文：

> 「具体启用的指标**以数据可得性合同为准**：可以输出 UNKNOWN，
> 但必须至少有**实际可复算的经营信息**和有依据的行业/产品内容，
> **不能整份报告只有缺失提示**。」

据此确立三条原则：

| # | 原则 |
|---|---|
| **P1** | **有实际可复算数据**的指标，才进首批 |
| **P2** | 无数据的指标**不假装启用**，如实标 `NOT_ENABLED_NO_DATA`，输出 UNKNOWN |
| **P3** | 首批**必须**包含至少一项可复算经营指标 + 有依据的行业/产品内容，避免"整份报告只有缺失提示" |

## 3. 明确**不启用**的指标（**如实标注理由**）

### 3.1 因缺数据不启用

| 编号 | 指标 | 理由 |
|---|---|---|
| **M14** | 可用现金余额 | 数据集 v2 **无冻结/质押标识** → `NOT_ENABLED_NO_DATA` |

| **M24–M25** | 前五大对手集中度 | **需对手解析**，归 WP05/CAP-03；**W-2 已确认不应删指标**，故保留在目录 |
| **M26** | 本行中间业务净收入 | 内部经营分析，非客户风险事实 |
| **M27–M28** | 票据 | 首批规则未涉及 |
| **M29** | 可见融资性负债余额 | **需跨行授权，未证实** |
| **M30** | 可见对外担保责任余额 | 同上 |

### 3.2 因无授权不启用

| 范围 | 指标 | 理由 |
|---|---|---|
| **I01–I12 全部** | 开票/税款/社保/用电/订单/产能/海关/跨境/渠道/续约 | **无数据可得性授权合同**（§6.3 明示按条件启用） |

> **重要**：数据集 v2 **已含**外部观察层（开票/税款/社保/用电/订单），
> 但**授权合同未建立** → 首批**不启用**，输出 UNKNOWN。
> **不得因数据存在就当作已获授权**（§2.4：「数据存在于社会系统中，不等于本项目已经可用」）。

## 4. 对 M21（授信使用率）的特殊说明

M21 是 **R08 的组成之一**，但数据集 v2 未含额度池结构。

**裁定**：
- M21 **不并入首批可复算**
- 但 **R08 仍启用**（依 §7.4：逾期事件**独立触发**，不依赖使用率）
- 这正好对应验收案例 **E04**：**使用率 35% + 现有逾期 → 仍须显示逾期**

**→ 即：M21 缺失不影响 R08 的正确性，反而验证了"不依赖使用率"的设计。**

## 6. 满足 §14.2「不能整份报告只有缺失提示」

| §14.2 要求 | 本裁定如何满足 |
|---|---|
| 至少一项**实际可复算的经营信息** | **19 项**中 **14 项可复算**（含 24 期月度趋势） |
| 有依据的**行业内容** | WP02 `SIM-IND-MANUFACTURING.json` 八维（含逐维依据要求） |
| 有依据的**产品内容** | WP04 设计 + A3 落地（ProductCard 13 字段） |

**→ 达成。**
