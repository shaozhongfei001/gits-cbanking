## 3. 逐项对照：我交付的 vs 真实应具备

| 知识维度 | 我当前的地图 | 真实访前准备 | 缺口 |
|---|---|---|---|
| **供应链/产业链** | ❌ 无 | 供应链三段式图谱 + 八维研判（政策/市场/技术/供应链/区域/风险/指数/竞争力） | **完全缺失** |
| **行内变动事实对账** | ⚠️ 仅「日均存款」1 项 | 营收、授信使用率、用电量、代发薪、结算量**多指标交叉校验** + 冲突检测 | **严重不足**（1 项 vs 多指标） |
| **历史承诺** | ❌ 无 | 历史沟通承诺提取 + 话术 + 行动计划（RUL-FRONT-004 事实引用规则） | **完全缺失** |
| **KYC 缺口** | ❌ 无 | KYC 缺口识别 + 按资金安全/合规风险/经营决策**三级优先级**排序 + 核实话术 | **完全缺失** |
| **产品推荐** | ⚠️ 仅「产品条款」被动引用 | 产品候选组合 + 三档匹配度 + **准入与互斥硬约束**过滤 | **不足**（缺准入与互斥） |
| **报告组装** | ❌ 无 | 七模块组装为一页 H5 + PDF | **完全缺失** |
| **能力（Skill）** | ⚠️ 仅 `SIM-CAP-INTERPRET` 1 个 | **7 个技能** | **1 vs 7** |

**量化**：我的地图 = **1 任务 + 3 引用 + 1 能力**；真实访前准备 = **8 任务 + 7 知识条目 + 7 技能 + 4 规则 + 3 数据源**。

## 5. 修正方向（不是加节点）

**应做**：把 `SIM-MAP-FINANCE` 从「3 个粗粒度引用」扩展为**对标 KERT 真实知识广度的装配清单**：

```
SIM-MAP-FINANCE（访前融资准备）
├─ 任务入口：SIM-TASK-TEMPLATE
├─ 知识条目（对标 KI-FRONT-001~007，至少 7 类）
│   ├─ 供应链图谱           ← KI-FRONT-001
│   ├─ 产业链八维研判       ← KI-FRONT-002
│   ├─ 行内变动事实对账     ← KI-FRONT-003（多指标，非仅日均存款）
│   ├─ 历史承诺事项         ← KI-FRONT-004
│   ├─ KYC 信息缺口         ← KI-FRONT-005
│   ├─ 产品候选组合         ← KI-FRONT-006
│   └─ 报告渲染模板         ← KI-FRONT-007
├─ 规则知识
│   ├─ KYC 核验制度         ← KI-RULE-001（准入）
│   └─ 产品准入与互斥制度   ← KI-RULE-002（准入）
├─ 能力（对标 7 个 bank-front 技能）
│   ├─ 供应链图谱能力
│   ├─ 八维研判能力
│   ├─ 事实对账能力
│   ├─ 承诺话术能力
│   ├─ KYC 缺口能力
│   ├─ 产品推荐能力
│   └─ 报告组装能力
└─ 数据源引用（T-CORE-001 / T-EXT-001 / T-MARKET-001）
```

**这与「加两个节点」的本质区别**：
- 加节点 = 结构上多两个空壳
- 补广度 = **每个节点背后有真实知识条目、规则与能力**，且数量对标权威源
