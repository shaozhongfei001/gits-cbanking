## 4. 纪律（本轮执行口径，后续沿用）

1. **不静默替换**：登记标题与现行版不一致时，标题保留为**沿革记录**，并在「登记行 / front matter / 抓取凭据」三处显式标注废止或替代关系。
2. **不拼装**：不自行合成"修订后合并正文"；修订用**原位标注 + 引官方修订件原文**的方式表达（`REG-CM-002` 已按此做）。
3. **不冒充**：摘要不得当原文入库；通知不得当条文入库（`REG-TF-002`/`REG-CB-002` 因此**未入库**）。
4. **必留痕**：每份入库均含 `source_url` + 抓取时间 + 抓取凭据文件 + 登记字节数/SHA-256（机器校验）；`clause_verified` 一律保持 `false`，`CLAUSE_VERIFIED` 只能由 Owner 核定。
5. **凭据强度如实声明**：入库件为**转写文本**（非原始 HTML 字节快照）⇒ `bytes_sha256` 只保证入库文件自身完整性，**不主张**与站点字节一致。
