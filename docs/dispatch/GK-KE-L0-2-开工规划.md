## 二、依赖分析（谁依赖谁）

```
L0-2 契约激活 ──┬──> L1-1 公共语义 ──> L2-1 语义查询 ──> L4-1 地图激活 ──> L4-2 GITS 闭环
                │                            │
                ├──> L1-2 模拟源 ─────────────┘（模拟数据支撑 L2-1 复算）
                │
                ├──> L2-2 注册中心 ──> L3-1 工厂与候选 ──> L3-2 审核发布 ──> L4-1（地图引用已发布资产）
                │
                └──> L5-1 Kuzu / L5-2 LightRAG（可关，不阻塞 L4 基础闭环）
                                                          └──> L6 运行验收（依赖全部）
```

**关键依赖链**：
1. **L0-2 是总前提**：所有后续工作单依赖"契约激活"（OpenAPI + 兼容策略 + 正负例）。
2. **L1-1 → L2-1 → L4-1 → L4-2**：公共语义 → 指标查询 → 地图激活 → 经营闭环（主业务链）。
3. **L1-2 → L2-1**：模拟数据支撑指标复算（C001 = 2,983,333.33）。
4. **L2-2 → L3-1 → L3-2**：注册中心 → 知识工厂 → 审核发布（知识加工链）。
5. **L3-2 → L4-1**：地图激活需要已发布的资产（知识内容）。
6. **L5-1/L5-2 不阻塞 L4**：图/RAG 是可关的增强项（C05/C08 明确）。

## 三、Wave 拆分（并行 + 串行）

### Wave A：L0-2 契约激活（唯一入口，串行）

- **范围**：审 CR-01~08、补完整 OpenAPI、定义兼容与生成策略、候选契约正负例、消费者驱动测试。
- **角色**：Feature Pilot（实现）+ Tech Lead（审批合同变更）+ 独立 QA（查冲突）。
- **产出**：`generated/gk-ke/v1` 完整 OpenAPI、正负例、字段映射表、兼容说明。
- **退出**：Owner 批准后激活（OC-01 收口）。

### Wave B：两个并行工作单（L0-2 完成后）

| 工作单 | 角色 | 说明 |
|---|---|---|
| **B1: L1-1 公共语义 + L2-1 语义查询**（串行） | Feature Pilot | 主业务链起点，先做公共语义再做指标查询 |
| **B2: L1-2 模拟源 + L2-2 注册中心**（并行） | Feature Pilot | 数据/注册两线独立，可并行 |

> L1-1 与 L1-2 可并行（公共语义 vs 模拟源无直接依赖）；L2-1 依赖 L1-1 + L1-2；L2-2 独立。

### Wave C：三条链并行

| 工作单 | 依赖 | 说明 |
|---|---|---|
| **C1: L3-1 工厂 + L3-2 审核发布** | L2-2 | 知识加工链 |
| **C2: L4-1 地图激活** | L2-1 + L3-2 | 地图引用已发布资产 + 指标 |
| **C3: L5-1 Kuzu / L5-2 LightRAG** | 无硬依赖（可提前 Spike） | 图/RAG 增强，可关 |

### Wave D：L4-2 GITS 闭环

- **依赖**：L4-1（地图）+ L2-1（指标）+ L3-2（已发布知识）。
- **范围**：解读→体检→推荐→确认→模拟跟进，3000 万场景、UNKNOWN、失效版本、超时对账。
- **退出**：业务专家验收（OB-C3）。

### Wave E：L6 运行验收

- **依赖**：全部。
- **范围**：并发、故障注入、升级/恢复、保留删除、完整追踪、独立 QA 包、部署锁文件。
- **退出**：无 BLOCKER/MAJOR；Owner 裁定试点范围。

## 五、每个工作单的统一纪律

1. 合同先行：改 `specs/` → `make generate` → `make check` → 写实现。
2. 禁止改 `generated/`、禁止 `git add .`、禁止启用隔离资产。
3. dev 只记 DEV_SELF_CHECK_PASS，独立 QA 才记 QA_PASS。
4. 失败先写 Loop `FAILURES.md`，再修复。
5. 每个 Loop 用 `make new-loop` 创建，绑定对应 CR 合同与验收。
