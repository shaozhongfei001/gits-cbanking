## 1. 请你确认什么（一句话）

**客户 / 法人 / 集团 / 产品身份的正式 A-Box 权威是银行源系统与数据平台，GITS 与 KERT 只持"带来源、时点、版本的授权投影"——请确认这一口径，并明确每个术语的源系统。**

## 2. 设计口径（委员会已认可方向，待你落到具体系统）

| 事实类型 | 设计认定的权威 | GITS/KERT 允许行为 |
|---|---|---|
| 客户、法人、集团、产品身份与正式状态 | **银行源系统 / 数据平台** | 保存带来源、时点、版本的授权投影，**不重新定义真相** |
| 知识文档、规则、知识地图、技能定义、产品知识版本 | KERT | 发布候选/审核版/`ACTIVE` 版；不代替业务主数据或审批结论 |
| 任务、案件、建议、人工决定、动作与回执 | GITS | 经营过程权威；引用知识版本与源数据时点 |
| 关系查询投影 | Kuzu / 图平台 | 仅索引与路径，**不得**成为业务决定权威 |
