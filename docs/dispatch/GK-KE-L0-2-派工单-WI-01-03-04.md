### 2.3 共同要求（C06 §1，必须落到 OpenAPI）

- `securitySchemes`: HTTP `Authorization` 票据传递（不是 API Key；沿用 C06 §1 原文语义）
- `servers`: `/{basePath}/gk-ke/v1`，不得与 `/api/v1` 冲突
- **幂等**：mutation operation 必须声明 `Idempotency-Key` header（required: false 但语义化）
- **乐观锁**：mutation 必须声明 `expectedVersion` 字段/参数
- **追踪**：全部 operation 声明 `correlationId` / `traceId`
- **格式**：时间 RFC3339（`format: date-time`）；金额**十进制字符串**（`type: string` + `pattern: ^-?\d+(\.\d+)?$`），**禁止 `type: number`**
- **失败响应**：405/403/404/409/422/503 使用统一 error 结构（沿用项目 `status/error/message/path/timestamp` 五段式）
- **禁用字段**：响应 schema 不得含服务器路径、凭据、内部 SQL

### 2.4 必带的扩展块（决策 D-2 / OC-01 落地）

```jsonc
"x-gk-ke-namespace": "gk-ke/v1",
"x-gk-ke-simulation-only": true,
"x-gk-ke-existing-mapping": {
  "KM-CORP-RM-PREVISIT": {"target": "SIM-MAP-FINANCE", "status": "pending_owner_confirmation"},
  "ASSET-KNOW-PRODUCT-CARDS": {"target": "SIM-ASSET-P001", "status": "pending_owner_confirmation"},
  "RP-CORP-RM-001": {"target": "SIM-ROUTE-001", "status": "pending_owner_confirmation"},
  "AC-PREVISIT-001": {"target": "gk-ke/v1:ActivationPlan", "status": "pending_owner_confirmation"}
},
"x-gk-ke-pi0-mapping": {
  "Assertion": "CTR-PK-ASM-001 (mapping, not replacement)",
  "ReleaseManifest": "CTR-PK-RLS-001 (mapping, not replacement)"
},
"x-gk-ke-root-map-discriminator": "mapType==ROOT (NOT mapId string match)"
```

`info.description` **必须**保留声明：
> 本命名空间为独立候选剖面，非现有 GITS/DKES/PI-0 API 的完整替代。

（此声明是 CR 审计风险 #24 的合同级防线。）
