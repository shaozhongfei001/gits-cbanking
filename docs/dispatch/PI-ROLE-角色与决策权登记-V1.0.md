## 2. 决策权矩阵（不可下放项已标注）

| 实现 | **Feature Pilot**（与 TL 不同上下文，显式声明） | TL 不得同上下文混写 | Loop `LOOP.yaml` scope |

| 合入 / 验收 / 冻结 | **Owner** | TL | Owner 签字 |
