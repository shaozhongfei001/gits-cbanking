## 2. 基线计数复现脚本（独立 QA 可用）

```bash
python3 - <<'EOF'
from rdflib import Graph
from rdflib.namespace import OWL, RDF
g = Graph(); g.parse("specs/semantic/gits-core.owl.ttl", format="turtle")
cls  = set(g.subjects(RDF.type, OWL.Class))
objp = set(g.subjects(RDF.type, OWL.ObjectProperty))
dtp  = set(g.subjects(RDF.type, OWL.DatatypeProperty))
print(f"classes={len(cls)} objectProps={len(objp)} datatypeProps={len(dtp)}")
# 期望输出：classes=32 objectProps=34 datatypeProps=1
EOF
sha256sum specs/semantic/gits-core.owl.ttl   # 期望前缀 705578d6324abd0c
```
