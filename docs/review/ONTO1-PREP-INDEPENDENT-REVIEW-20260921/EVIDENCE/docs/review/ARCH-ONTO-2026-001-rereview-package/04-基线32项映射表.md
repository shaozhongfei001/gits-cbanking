## D. 映射等价性规则（呼应命名空间 ADR）

- 保留原名 + 语义不变：`owl:equivalentClass`/`owl:equivalentProperty` 候选（新旧 IRI 身份可互换）。
- 重构/改名（Customer→CustomerRole 等）：语义收窄/改变，**禁止 equivalentClass**，用 SKOS `closeMatch` 或项目映射状态 `REMODELED`。
- 转制品类型（ActivationContract 等）：OWL 类与 Schema 对象不同构，用项目映射状态 `TRANSFORMED`，经注册表 RDF 投影保持图查询能力。
