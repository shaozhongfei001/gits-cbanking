# PSO / ICO 临时任命登记与条款禁令核查（准备项 4）

## 1. 临时任命（继续）
| 角色 | holder | status | 说明 |
|---|---|---|---|
| 公共语义 Owner（PSO） | 项目 Owner（邵钟飞） | `interim` | 决定词义 / 本体 / 词表 / 语义版本 |
| Integration Contract Owner（ICO） | 项目 Owner（邵钟飞） | `interim` | 决定接口表达 / 版本绑定 / 兼容性 / 消费者契约；**不得反向改写 PSO 已批准语义** |

**明确登记（避免误用）**：**评审委员会的独立性要求（V8）不适用于这两项临时任命**。
V8 只约束《14 签署页》的**评审委员会**构成（须具名独立评审角色分别确认）；PSO/ICO 属 Owner 临时兼任的**职责角色**，
两者不可互相援引：既不得用 V8 否定 PSO/ICO 临时任命的有效性，也不得用 PSO/ICO 兼任去证明评审已具独立性。
