## 9. 访前准备·目标与缺口（P14-1 / PrevisitGapsView）

### 9.1 页面结构

```
┌─────────────────────────────────────────────────────────────┐
│ ObjectHeader: 互动 Interaction · {journeyId}                │
├─────────────────────────────────────────────────────────────┤
│ StagePath: ●访前目标 ─── ○证据装配 ─── ○访前包 ─── ○会中   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ ┌─ 客户信息摘要 ────────────────────────────────────────┐  │
│ │ NDescriptions: 客户名/行业/风险/层级                    │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ ┌─ 缺口分析 ────────────────────────────────────────────┐  │
│ │ KYC 缺口: 3项                                          │  │
│ │ ┌──────────────────────────────────────────────────┐  │  │
│ │ │ 缺口类型  │ 缺口描述          │ 状态              │  │  │
│ │ │ 行业信息  │ 缺少行业调研数据   │ 待补齐            │  │  │
│ │ │ 财务数据  │ 最新财报未获取     │ 待补齐            │  │  │
│ │ │ 准入条件  │ 行业准入未核验     │ 待补齐            │  │  │
│ │ └──────────────────────────────────────────────────┘  │  │
│ │                                                        │  │
│ │ 产品缺口: 2项                                          │  │
│ │ 信息缺口: 1项                                          │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ [下一步: 证据装配 →]                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 9.2 缺口分析规格

| 属性 | 值 |
|------|-----|
| 分类 | KYC缺口 / 产品缺口 / 信息缺口 |
| 每类 | 可折叠 NCollapse, 默认展开 |
| 缺口项 | NDescriptions, label=缺口类型, content=缺口描述+状态 |
| 状态标签 | 待补齐=warning, 已补齐=success, 不适用=info |

## 12. 会中协作（P15 / InMeetingAssistant）

### 12.1 页面结构

```
┌─────────────────────────────────────────────────────────────┐
│ ObjectHeader: 互动 Interaction · {journeyId}                │
├─────────────────────────────────────────────────────────────┤
│ StagePath: ●访前准备 ─── ●会中协作 ─── ○访后核验            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ ┌─ 会中笔记 ────────────────────────────────────────────┐  │
│ │ NInput type=textarea, placeholder="记录会谈要点..."    │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ ┌─ 实时建议 ────────────────────────────────────────────┐  │
│ │ 基于对话内容的实时产品/话术建议                         │  │
│ │ NCard: 建议内容 + [采纳] [忽略]                        │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ ┌─ 客户信息速览 ────────────────────────────────────────┐  │
│ │ 关键指标 + 风险标签 + 信号摘要                         │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ [结束会议 → 访后核验]                                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 12.2 会中笔记规格

| 属性 | 值 |
|------|-----|
| 输入框 | NInput type=textarea, rows=6, autosize |
| 占位符 | "记录会谈要点..." |
| 边框 | focus 时 border-color=var(--brand-primary) |

### 12.3 实时建议

| 属性 | 值 |
|------|-----|
| 容器 | NCard, border-left=3px solid var(--v8-amber) |
| 建议内容 | 14px, 最多3行 |
| 采纳按钮 | NButton size=small type=primary |
| 忽略按钮 | NButton size=small quaternary |

## 13. 访后核验与受控回写（P16 / PostvisitReconcileView）

### 13.1 页面结构

```
┌─────────────────────────────────────────────────────────────┐
│ ObjectHeader: 互动 Interaction · {journeyId}                │
├─────────────────────────────────────────────────────────────┤
│ StagePath: ●访前准备 ─── ●会中协作 ─── ●访后核验            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ ┌─ 核验清单 ────────────────────────────────────────────┐  │
│ │ ☐ 会中笔记已确认                                      │  │
│ │ ☐ 客户信息已更新                                      │  │
│ │ ☐ 承诺事项已记录                                      │  │
│ │ ☐ 后续行动已安排                                      │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ ┌─ CRM 回写预览 ────────────────────────────────────────┐  │
│ │ 即将回写的内容摘要                                     │  │
│ │ NDescriptions: 回写字段 + 值                           │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ ┌─ 回写状态 ────────────────────────────────────────────┐  │
│ │ 待回写 / 回写中 / 已回写 / 回写失败                    │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ [确认并回写] [完成旅程]                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 13.2 核验清单规格

| 属性 | 值 |
|------|-----|
| 布局 | NCheckboxGroup, 垂直排列 |
| 每项 | h=36px, font-size=14px |
| 已完成 | color=var(--v8-teal), check-icon |
| 未完成 | color=var(--v8-steel) |

### 13.3 CRM 回写状态

| 状态 | 颜色 | 图标 |
|------|------|------|
| 待回写 | var(--v8-faint) | ○ |
| 回写中 | var(--brand-primary) | ◌ (spinner) |
| 已回写 | var(--v8-teal) | ✓ |
| 回写失败 | var(--color-danger) | ✗ + 重试按钮 |
