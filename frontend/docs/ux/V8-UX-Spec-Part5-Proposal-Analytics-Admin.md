## 18. 建议书列表（P23 / ProposalsView）

### 18.1 页面结构

```
┌─────────────────────────────────────────────────────────────┐
│ ProposalDegradeShell (C2 降级外壳)                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ ┌─ 工具栏 ──────────────────────────────────────────────┐  │
│ │ [新建建议书]  [导入草稿](disabled + tooltip)           │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ ┌─ 建议书列表 ──────────────────────────────────────────┐  │
│ │ NDataTable:                                            │  │
│ │ 客户 │ 建议书名称 │ 生成时间 │ 状态 │ 章数/技能/引用  │  │
│ │ XX公司│ 2026年Q4方案 │ 09-25 10:00 │ 草稿 │ 8/3/12  │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ 空态: NEmpty "暂无建议书"                                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 18.2 降级说明

| 属性 | 值 |
|------|-----|
| 降级原因 | C2 降级：不调用建议书写接口，不落库 |
| 导入草稿 | DisabledAction, disabled=true, reason="C2 降级：不支持导入" |
| 数据来源 | useProposalDraftStore（浏览器会话内暂存） |
| 空列表 | 真实空态，不编造建议书行 |

### 18.3 建议书名称

| 属性 | 值 |
|------|-----|
| 渲染 | `<a>` 链接, href=详情页路由 |
| 样式 | color=var(--brand-primary), hover=underline |
| 点击 | 左键路由跳转, 支持中键/右键新开 |
| 溢出 | ellipsis + tooltip |
