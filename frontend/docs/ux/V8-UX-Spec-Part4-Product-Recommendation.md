```
│ │ │ 字段路径          │ 值          │ 知识状态         │  │  │
│ │ │ identity.code    │ LG001       │ SUPPORTED ✓     │  │  │
│ │ │ compliance.basis  │ 待核验      │ STALE ⚠         │  │  │
│ │ │ eligibility.segment│ 大型企业   │ SUPPORTED ✓     │  │  │

│                                                             │

```

### 15.2 知识状态标签

| 状态 | NTag type | 颜色 | 含义 |
|------|-----------|------|------|
| SUPPORTED | success | 绿 | 知识库支持 |
| CONFLICT | error | 红 | 来源冲突 |
| STALE | warning | 琥珀 | 数据过期 |
| NOT_APPLICABLE | info | 蓝 | 不适用 |

### 15.3 产品族顺序

按 `FAMILY_ORDER` 固定排列：流动资金融资 → 贸易融资 → 结算服务 → 现金管理 → 跨境金融 → 投资银行

### 17.2 创建表单规格

| 属性 | 值 |
|------|-----|
| 客户选择 | NSelect, 可搜索, 数据源=fetchCustomers |
| 经营上下文 | NRadioGroup: 经营案例(默认) / 客户旅程 |
| 需求候选 | NSelect multiple, 数据源=needVersionIds |
| 产品域 | NSelect multiple, 选项=PRODUCT_DOMAIN_LABELS |
| 推荐目标 | NInput, placeholder="描述推荐目标" |
| 提交 | NButton type=primary, "发起推荐" |

### 17.3 推荐状态流转

```
REQUESTED → CONTEXT_ASSEMBLING → HARD_FILTERING → MATCHING
→ PROPOSAL_READY → AWAITING_HUMAN → APPROVED/MODIFIED/REJECTED/HELD
```

| 状态 | StagePath 位置 | 颜色 |
|------|---------------|------|
| REQUESTED/CONTEXT_ASSEMBLING/HARD_FILTERING | 资格与缺口 | 蓝 |
| MATCHING | 匹配与组合 | 蓝 |
| PROPOSAL_READY/AWAITING_HUMAN | 人工决定 | 琥珀 |
| APPROVED | 完成 | 绿 |
| MODIFIED | 完成(修改) | 蓝 |
| REJECTED | 完成(拒绝) | 红 |
| HELD | 暂缓 | 灰 |

### 17.4 决定面板规格

| 操作 | 按钮 | 样式 |
|------|------|------|
| 批准 | NButton | type=success |
| 修改 | NButton | type=warning |
| 拒绝 | NButton | type=error |
| 暂缓 | NButton | type=default |
