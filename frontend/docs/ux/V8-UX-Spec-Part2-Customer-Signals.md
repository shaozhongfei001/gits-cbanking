```
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ 【表格视图】                                                │
│ ┌──────────────────────────────────────────────────────┐   │
│ │ 客户名  │ 客户ID │ 行业   │ 规模  │ 层级      │ 风险  │   │
│ ├──────────────────────────────────────────────────────┤   │
│ │ XX公司  │ C001  │ 制造业 │ 大型  │ KEY       │ ●HIGH │   │
│ │ YY集团  │ C002  │ 金融   │ 中型  │ STRATEGIC │ ●MED  │   │
│ └──────────────────────────────────────────────────────┘   │
│                                                             │
│ 【卡片视图】                                                │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐                    │

│ │ [tag][tag]│ │           │ │ [tag]    │                    │
│ └──────────┘ └──────────┘ └──────────┘                    │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 CustomerCard 规格

| 属性 | 值 |
|------|-----|
| 容器 | NCard hoverable, cursor=pointer |
| 悬停 | transform: translateY(-2px), box-shadow: 0 4px 12px rgba(0,51,102,0.15) |
| 过渡 | 0.2s ease |
| 客户名 | 16px, font-weight=600, color=#003366 |
| 行业/规模 | 13px, label=color(#8c8c8c), value=color(#333), font-weight=500 |
| 层级 | 13px, font-weight=500, color=#b8860b |
| 标签 | NTag size=small type=info, 最多3个, flex-wrap |
| 风险 | RiskBadge 组件（绿/黄/红） |
| 点击 | 路由到 `/customers/:id` |

### 5.3 视图切换

| 选项 | 说明 |
|------|------|
| 表格 | NDataTable, 可排序, 可筛选, 行点击导航 |
| 卡片 | 响应式网格, sm=1列, md=2列, lg=3列, xl=4列 |

### 5.4 四态

| 状态 | 表现 |
|------|------|
| idle | NEmpty "尚未加载" |
| loading | NSpin + "加载中…" |
| error | NResult + 重试 |
| success | 表格/卡片视图 |

### 6.2 CustomerRecordTabs 规格

## 7. 经营信号（P08）

### 7.1 页面结构

```
┌─────────────────────────────────────────────────────────────┐
│ ObjectHeader: 经营信号 Signal · 经营信号                     │
├─────────────────────────────────────────────────────────────┤
│ SignalsDomainTabs                                           │
│ [经营旅程] [经营信号●] [互动对象]                             │
├─────────────────────────────────────────────────────────────┤
│ [搜索信号内容/客户名/ID...]                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ ┌─ 信号列表 ────────────────────────────────────────────┐  │
│ │ 信号ID │ 客户    │ 类型        │ 状态 │ 内容           │  │
│ │ S001   │ XX公司  │ OPPORTUNITY │ NEW  │ 存款下降30%... │  │
│ │ S002   │ YY集团  │ RISK        │ ACK  │ 担保链预警...  │  │
│ └───────────────────────────────────────────────────────┘  │
│                                                             │
│ 行点击 → SignalRecordView (/signals/:id)                    │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 SignalsDomainTabs 规格

| 属性 | 值 |
|------|-----|
| 布局 | flex, gap=4px, border-bottom=1px solid var(--gits-line) |
| 选项卡 | h=36px, padding=0 14px, font-size=13px, font-weight=600 |
| 默认色 | var(--gits-muted) #5b708b |
| 激活色 | var(--gits-blue-600) #1976d2, border-bottom=2px solid |
| 路由映射 | 经营旅程→/engagement, 经营信号→/signals, 互动对象→/engagements |

### 7.3 信号列表

| 属性 | 值 |
|------|-----|
| 数据源 | fetchCustomers + fetchCustomerContext → 派生信号 |
| 筛选 | 信号内容/客户名/信号ID 模糊匹配 |
| 排序 | 按时间降序 |
| 行点击 | 路由到 /signals/:id |
| 信号类型标签 | OPPORTUNITY=蓝, RISK=红, INFO=灰 |
| 信号状态标签 | NEW=蓝, ACK=绿, DISMISSED=灰 |

### 8.2 StagePath 规格（全局复用）

| 属性 | 值 |
|------|-----|
| 布局 | flex, 水平排列, 步骤间连线 |
| 步骤圆点 | 24px 圆形 |
| 已完成 | bg=var(--v8-teal) #1A827E, label=var(--v8-ink) |
| 当前 | bg=var(--brand-primary) #3B58C8, label=var(--brand-primary) |
| 未完成 | bg=var(--v8-line) #D8DEE4, label=var(--v8-faint) |
| 连线 | 2px, 已完成=var(--v8-teal), 未完成=var(--v8-line) |
| 标签 | 13px, font-weight=600 |

### 8.3 HighlightsMetrics 规格

| 属性 | 值 |
|------|-----|
| 布局 | flex, gap=24px |
| 指标项 | 数值=20px font-weight=700, 标签=12px color=var(--v8-faint) |
| 变化指示 | ↑绿色 / ↓红色, 12px |

### 8.4 关键工作 Checklist

| 属性 | 值 |
|------|-----|
| 布局 | 垂直列表, 每项 h=36px |
| 复选框 | NCheckbox, 13px |
| 已完成 | text-decoration=line-through, color=var(--v8-faint) |
