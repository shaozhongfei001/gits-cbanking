# CitiDirect 风格前端设计审阅提示词

> 复制以下内容发给外部智能体（如 Claude、GPT、Gemini 等）进行设计审阅。

---

## 审阅请求

你是一位资深的前端设计系统专家，擅长企业级 SaaS / 机构银行数字产品的视觉设计评审。请审阅以下 CitiDirect 风格前端设计改造方案，给出具体、可操作的改进建议。

### 背景

这是一个"对公客户经营工作台"（GITS）的前端，从 V5.1 暗色金融科技风翻转为 V6.0 CitiDirect 白画布机构银行风。参考对象是花旗 CitiDirect BE® 全球机构银行数字平台。

### 审阅重点

请从以下 7 个维度逐一评价，每个维度给出 **1-5 分** + **具体问题清单** + **改进建议**：

1. **色彩系统合理性**
   - 品牌蓝(#002d72)与交互蓝(#056dae)的分离是否清晰？
   - 蔚蓝色作为唯一交互色是否足够区分不同交互类型（主操作/次操作/链接/激活态）？
   - 背景层级（白→浅灰→微蓝灰）是否足够区分信息层次？
   - 暗色模式是否需要更认真的对待（而非"最小兼容"）？

2. **排版与信息密度**
   - 14px 正文对机构银行工作台是否偏小？CitiDirect 实际用多大？
   - 中文字体回退链是否合理？Overpass/Interstate 未加载时效果如何？
   - 展示字体 Noto Serif SC 在白画布上是否违和？

3. **侧边栏设计**
   - 白底侧边栏 + 深海军蓝品牌区的组合是否视觉断裂？
   - 导航项 38px 高度在白底上是否显得稀疏？
   - 激活态（左侧蔚蓝竖线 + 浅蓝底）是否足够醒目？
   - 用户区底色 #f0f2f5 与侧边栏底色 #f8f9fb 的微妙差异是否有意义？

4. **登录页设计**
   - 纯白底 + 孤立卡片是否过于"模板化"？
   - 品牌条与表单区的视觉权重是否平衡？
   - 缺少装饰性元素（插画/图案/渐变）是否让页面显得空洞？

5. **组件一致性**
   - 8px 统一圆角是否适合所有元素？按钮/卡片/输入框/弹窗是否应差异化？
   - 极轻阴影是否足以区分卡片与背景？
   - Section 标题的蔚蓝竖线是否与 CitiDirect 风格一致？

6. **CitiDirect 还原度**
   - 与真实 CitiDirect BE® 的差距在哪？
   - 是否有被忽略的 CitiDirect 设计特征（如特定的间距节奏、字体粗细对比、数据展示范式）？
   - "白画布"理念是否被正确理解——CitiDirect 的白画布是"无装饰"还是"有克制装饰"？

7. **整体感受**
   - 这个设计给人的第一印象是什么？（用一个词/短语描述）
   - 如果你是机构银行的客户经理，每天使用 8 小时，这个界面会让你感觉如何？
   - 最大的 3 个改进机会是什么？

### 设计规格

以下是完整的设计 Token 和组件样式规格：

---

**基础色板**：

| Token | 色值 | 用途 |
|-------|------|------|
| 品牌蓝(Navy) | `#002d72` | 仅品牌区（侧边栏顶部64px、登录页品牌条） |
| 交互蓝(Cerulean) | `#056dae` | 所有可交互元素：链接、按钮、激活态、徽章 |
| 交互蓝hover | `#2a8fc9` | 交互元素hover |
| 交互蓝pressed | `#004f80` | 交互元素按下 |
| 画布白 | `#ffffff` | 页面底色 |
| 浅灰面 | `#f4f4f4` | 条带/交替行 |
| 侧边栏底 | `#f8f9fb` | 侧边栏背景 |
| 主文字 | `#333333` | 正文 |
| 次文字 | `#666666` | 辅助文字 |
| 三级文字 | `#888888` | 标签/禁用 |
| 分隔线 | `#dddddd` | 边框/分隔 |
| hover底 | `#eef4f9` | 微蓝灰hover |
| active底 | `#d6e8f3` | 按下态 |
| 激活浅底 | `#e8f4fa` | 激活态背景 |
| 成功 | `#00823B` | 绿色 |
| 警告 | `#7a4b00` | 深琥珀 |
| 危险 | `#d60000` | 红色 |

**排版**：
- UI字体：Overpass, Interstate, -apple-system, PingFang SC, Microsoft YaHei, ...
- 展示字体：Noto Serif SC, STSong, SimSun, Georgia, serif
- 正文：14px / 辅助：13px / 标签：12px
- 导航项：13px / 品牌名：18px（侧边栏）/ 22px（登录页）

**圆角**：统一 8px（小元素6px，大卡片12px）

**阴影**：极轻 — xs=`0 1px 2px rgba(0,0,0,0.04)`, sm=`0 1px 3px rgba(0,0,0,0.06)`

**侧边栏**：
- 白灰底 #f8f9fb，右边框 1px #dddddd
- 品牌区：深海军蓝 #002d72，高64px
- 导航项：38px高，8px圆角，默认#555555
- hover：底色#eef4f9，文字#056dae
- active：底色#e8f4fa，文字#056dae 600，左侧3px蔚蓝竖线
- 用户区：底色#f0f2f5，border-top 1px #dddddd

**顶栏**：
- 56px高，白底，1px #dddddd下边框
- 阴影：0 1px 2px rgba(0,0,0,0.04)

**登录页**：
- 纯白底，居中420px卡片
- 卡片：8px圆角，1px #dddddd边框，阴影0 4px 12px rgba(0,0,0,0.06)
- 品牌条：#002d72，padding 24px 32px
- 表单区：padding 28px 32px 24px

**旧版对比**：
- 侧边栏：深蓝渐变→白灰
- 激活色：金色→蔚蓝
- 页面底：冷白→纯白
- 登录页：深蓝渐变+毛玻璃→白底+品牌条卡片
- 圆角：6-12px混合→8px统一
- 阴影：冷色调中等→极轻柔
